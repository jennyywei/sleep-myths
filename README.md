# A Game of Sleep and Dreams

Sleep quiz game for PSYC 135 Sleep and Dreams. Built with **Next.js 15**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

Prove your sleep knwoledge by blasting the correct answer cloud before time runs out!

Vercel Link: [sleep-facts.vercel.app/](https://sleep-facts.vercel.app/)

---

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

---

## How to Run Locally

**Requirements:** Node.js ≥ 18.17, npm ≥ 9

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Production build 
npm run build && npm start
```
